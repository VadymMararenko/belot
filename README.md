# Клабор: Счёт / Клабор: Рахунок

Первая рабочая версия офлайн-счётчика для деберца (клабора) на Flutter.

## Что уже работает

- русский и украинский интерфейс;
- режимы `1×1`, `1×1×1`, `2×2`;
- конечный счёт `501`, `1001` или `1501`;
- сохранение активной партии на устройстве;
- выбор общей суммы раздачи, её ручной ввод и ручной бонус;
- объявления: 4 валета, 4 девятки, 4 туза, 4 десятки, 4 короля, 4 дамы;
- автоматический остаток очков для двух и трёх сторон;
- выбор играющей стороны;
- автоматический байт;
- штраф `−100` за ноль очков для любой стороны;
- четвёртый и последующие болты дают `−100`;
- выбор «Пощадить / Не щадить» при нуле у играющей стороны с тремя болтами;
- висячка с сохранением сдающего или деление очков;
- история раздач и отмена последней;
- немедленная победа при достижении заданного счёта;
- нет рекламы, Firebase, аналитики, трекеров и сетевой логики.

## Первый запуск

В корне проекта выполни:

```bash
flutter create --platforms=android --org com.klabor .
flutter pub get
flutter test
flutter run
```

Команда `flutter create` добавит стандартные Android-файлы для установленной у
тебя версии Flutter и не заменит код в `lib/`.

В Android Studio можно открыть корневую папку проекта, дождаться индексации,
выбрать эмулятор или подключённый телефон и запустить `lib/main.dart`.

## Приватность

Приложение хранит активную партию локально через `shared_preferences`. Оно не
отправляет данные в интернет и не содержит рекламных или аналитических SDK.

## Текущие ограничения первой версии

- история сохраняет активную партию, но отдельный архив завершённых партий ещё
  не добавлен;
- реализована отмена последней раздачи; редактирование любой старой раздачи
  будет добавлено после проверки основной логики;
- светлая тема и расширенный редактор правил запланированы для следующей версии.
